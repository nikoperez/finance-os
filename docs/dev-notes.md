# Development Rules

## Principle 1: Build Incrementally
Do not build multiple features at once.

---

## Principle 2: Every feature must have:
- API endpoint
- Database model (if needed)
- Basic test or validation

---

## Principle 3: Keep backend simple first
No overengineering:
- No microservices
- No CQRS
- No event systems (yet)

---

## Principle 4: Ship MVP first
Only after MVP is working should advanced features be added.
