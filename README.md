# Finance OS

A modular personal finance platform for tracking spending, budgeting, and financial insights.

---

## Vision

Finance OS helps users understand where their money goes and build better financial habits through clear analytics and structured tracking.

---

## MVP Scope

- User authentication (JWT)
- Income & expense tracking
- Monthly budget tracking
- Spending breakdown dashboard

---

## Architecture

- Frontend: React + TypeScript (planned)
- Backend: ASP.NET Core Web API
- Database: PostgreSQL (Docker)
- Authentication: JWT

---

## Project Structure

```
frontend/   → React app (future)
backend/    → API server
docs/       → design & planning
database/   → schema definitions
infra/      → Docker & deployment
```
